Welcome to my Coffee Website project!

This is a responsive coffee website developed using HTML, CSS, and JavaScript. The project was created to practise and improve my frontend web development skills.

🚀 Project Overview

The Coffee Website provides visitors with information about a coffee business, including its services, menu, company information, and customer testimonials.

🛠️ Technologies Used

- HTML – For structuring the website.
- CSS – For styling and responsive design.
- JavaScript – For interactive features and DOM manipulation.

✨ Features

- Home page with a welcome section.
- About Us section.
- Coffee menu section.
- Customer testimonials.
- Responsive navigation menu.
- Responsive website layout.
- Interactive navigation using JavaScript.

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.htm` in your browser.
4. Explore the website.
